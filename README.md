# MongoDB-TrabalhoDeFaculdade
Este projeto faz parte de um desafio acadêmico para praticar operações de banco de dados NoSQL utilizando o MongoDB Compass e o Mongo Shell.

# Etapas do Projeto
## **Etapa 1: Modelagem e Inserção.**
Criação da collection vendas e carga inicial de documentos com dados de clientes (nome, e-mail, telefone e status VIP)
